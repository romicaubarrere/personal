# Formato de Comunidad y eventos

## Objetivo

Mostrar la construcción de comunidad como experiencia real de gestión sin confundirla con las participaciones de Romina como oradora.

## Patr&oacute;n visual

- Las comunidades se presentan como credenciales con nombre, rol y período.
- El trabajo sostenido se presenta como hojas de proyecto dentro de la carpeta del estudio.
- Cada evento organizado usa una hoja con comunidad, fecha, rol, formato, lugar, asistencia, detalle, responsabilidades, resultado y evidencia cuando existe.
- Las charlas usan la misma familia visual en una sección separada. Las marcas `ORA`, `PAN` y `PON` sustituyen la numeración genérica y describen el rol real.

## Reglas editoriales

- `Organización` y `participación como oradora o panelista` son roles distintos.
- Las cifras tomadas de Advocu se identifican como tales.
- Si LinkedIn y Advocu no permiten reconstruir las responsabilidades individuales, se publica esa limitaci&oacute;n en lugar de inferir tareas.
- El resultado informa solamente lo verificable: realización, formato, contenido y asistencia registrada.
- Los campos pendientes permanecen marcados; no se completan por intuici&oacute;n.

## Habilidades transferibles visibles

El conjunto permite ver continuidad, coordinación de formatos presenciales y virtuales, trabajo con comunidades y speakers, y capacidad para sostener un registro verificable. No se atribuyen a Romina tareas individuales que las fuentes no documenten.
